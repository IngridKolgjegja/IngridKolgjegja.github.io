Power BI Bookmarks Explained

Bookmarks in Power BI let you save the current state of a report page and return to it later. They are especially useful for navigation, interactive dashboards and show-and-hide effects.

What does a bookmark save?

A bookmark can capture several parts of the current report state, including:

  • filters
  • slicer selections
  • visual visibility
  • sort order
  • drill position
  • the current report page

This means you can create different report views and let the user switch between them.

How to create a bookmark

  1. Open the report page you want to save.
  2. Set the filters, slicers and visuals exactly as you want them.
  3. Open the Bookmarks pane.
  4. Select Add.
  5. Rename the bookmark so its purpose is clear.

For example: 

Overview
Sales View
Customer View
Filter Panel Open
Filter Panel Closed

Using bookmarks for navigation

You can connect buttons to bookmarks.

Select a button, enable its action, and choose: 

Action → Bookmark

Then select the bookmark you want the button to activate.

This lets you build custom report navigation without relying only on standard page tabs.

Show and hide visuals with bookmarks

One of the most useful bookmark techniques is showing and hiding groups of visuals.

For example, you can create a filter panel that appears when the user clicks a button.

The usual workflow is:

  1. Open the Selection pane.
  2. Choose which visuals should be visible.
  3. Create a bookmark for the visible state.
  4. Hide the visuals.
  5. Create another bookmark for the hidden state.
  6. Connect buttons to the two bookmarks.
Tip: bookmarks and the Selection pane work very well together when creating menus, pop-ups and custom filter panels.

Data, display and current page

A bookmark can include different types of information.

Data

Saves filters, slicers and other data-related state.

Display

Saves which visuals are visible or hidden.

Current page

Saves the page associated with the bookmark.

Depending on what you want the bookmark to do, you may want to include or exclude some of these options.

Why slicers sometimes reset

A common problem is that clicking a bookmark unexpectedly changes slicer selections.

This often happens because the bookmark was created with the Data option enabled.

If you want a bookmark to change only visual visibility, try disabling the Data option for that bookmark.

Bookmarks for switching views

You can also use bookmarks to switch between different visual layouts.

For example:

  • chart view vs table view
  • monthly view vs yearly view
  • sales view vs customer view
  • summary view vs detailed view

Instead of placing every visual on the screen at the same time, bookmarks can make the report cleaner and easier to navigate.

Bookmark Navigator

Power BI also includes a Bookmark Navigator visual.

This can automatically create navigation buttons based on your bookmarks and can be useful when you have several saved report states.

Common bookmark problems

1. Bookmark changes the wrong filters

Check whether the Data option is enabled.

2. Visual does not appear or disappear

Check the Selection pane and update the bookmark after changing visibility.

3. Bookmark does not reflect recent changes

Bookmarks do not automatically update every time you edit the report state. Update the bookmark after making changes.

4. Button does nothing

Check that the button action is enabled and linked to the correct bookmark.

Quick checklist

  • Did you create the bookmark after setting the correct report state?
  • Should the bookmark capture Data?
  • Should it capture Display?
  • Are the correct visuals visible in the Selection pane?
  • Did you update the bookmark after making changes?
  • Is the button linked to the correct bookmark?
