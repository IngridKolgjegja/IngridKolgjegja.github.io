Power BI Drillthrough Explained

Drillthrough in Power BI allows users to move from a summary view to a detailed page that is automatically filtered for the item they selected.

It is useful when you want to keep the main dashboard clean while still giving users access to detailed information.

What is drillthrough?

Imagine you have a sales dashboard showing sales by customer.

Instead of showing every customer detail on the main page, you can create a separate customer detail page.

When the user right-clicks a customer and selects drillthrough, Power BI opens the detail page filtered for that customer.

Example

Suppose your main page contains: 

Customer Name
Total Sales
Number of Orders
Average Order Value

You create another page called: 

Customer Details

On that page, you might show:

  • customer information
  • sales history
  • orders over time
  • products purchased
  • KPIs for that customer

How to create a drillthrough page

  1. Create a new report page.
  2. Add the visuals you want to show on the detail page.
  3. Drag the drillthrough field into the Drillthrough filters area.

For example: 

Customers[Customer Name]

Now Power BI knows that this page should be filtered by customer.

How users activate drillthrough

On the main report page, the user can right-click a data point related to the same field.

For example: 

Right-click customer → Drill through → Customer Details

The detail page opens with the selected customer already applied as a filter.

Important: the source visual must contain a field that matches the drillthrough field, directly or through the current filter context.

Add a back button

A drillthrough page should normally include a back button so users can easily return to the previous page.

Power BI can automatically create a back button when you set up drillthrough.

You can also add one manually using: 

Insert → Buttons → Back

Keep all filters

Power BI includes a setting called Keep all filters.

When enabled, other filters from the source page can also be passed to the drillthrough page.

For example, if the user has selected: 

Year = 2026
Region = Europe
Customer = ABC Ltd

the drillthrough page can preserve those filters as well.

Multiple drillthrough fields

You can add more than one field to the drillthrough filter area.

For example: 

Customer
Region

This gives you more control over which context is passed to the detail page.

Common drillthrough use cases

  • Customer details
  • Product details
  • Employee details
  • Store performance
  • Regional analysis
  • Transaction-level details

Common drillthrough problems

1. Drillthrough option does not appear

Check that the source visual contains the same field or a compatible field used in the drillthrough filter.

2. Detail page shows too much data

Check whether the correct drillthrough field is being passed and whether other page filters are interfering.

3. Filters are not preserved

Check the Keep all filters setting.

4. User cannot return easily

Add a back button to the drillthrough page.

When to use drillthrough

Drillthrough is especially useful when your dashboard contains summary information, but users sometimes need detailed analysis.

Instead of overcrowding the main page, you can separate summary and detail views.

Quick checklist

  • Did you create a dedicated detail page?
  • Did you add the correct drillthrough field?
  • Does the source visual contain that field?
  • Should other filters be preserved?
  • Did you add a back button?
  • Does the detail page show the expected filtered data?
