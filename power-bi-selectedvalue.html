Power BI SELECTEDVALUE Explained

SELECTEDVALUE is one of the most useful DAX functions when you want a measure or label to react to a user's selection in a slicer or visual.

Basic syntax

SELECTEDVALUE(
    Table[Column],
    "Alternative Result"
)

Power BI returns the selected value when exactly one value is available in the current filter context.

If there is no single value, Power BI returns the alternative result.

Example

Imagine you have a product slicer and want to display the selected product in a card. 

Selected Product =
SELECTEDVALUE(
    Products[Product Name],
    "All Products"
)

If the user selects Laptop, the result is: 

Laptop

If multiple products are selected, the result is: 

All Products

Using SELECTEDVALUE for dynamic titles

You can combine SELECTEDVALUE with text to create a dynamic title. 

Dynamic Title =
"Sales for " &
SELECTEDVALUE(
    Products[Product Name],
    "All Products"
)

This could display: 

Sales for Laptop

or: 

Sales for All Products

Using a custom fallback

You are not limited to text such as "All Products". You can use any alternative value that makes sense for your report. 

Selected Region =
SELECTEDVALUE(
    Geography[Region],
    "Multiple or no regions selected"
)
Important: SELECTEDVALUE returns the selected value only when there is exactly one distinct value in the current filter context.

SELECTEDVALUE and BLANK()

If you do not provide an alternative result, SELECTEDVALUE returns BLANK() when there is not exactly one value. 

Selected Customer =
SELECTEDVALUE(
    Customers[Customer Name]
)

This is useful when you want a card or label to stay empty until the user makes a specific selection.

Common use cases

  • Dynamic chart titles
  • Dynamic KPI labels
  • Showing the selected customer, product or region
  • Changing measure behaviour based on slicer selections
  • Displaying a custom message when no single value is selected

SELECTEDVALUE vs HASONEVALUE

SELECTEDVALUE is useful when you want to retrieve the actual selected value.

HASONEVALUE is useful when you only want to check whether there is exactly one value in the current filter context. 

Show Sales =
IF(
    HASONEVALUE(Products[Product Name]),
    [Total Sales],
    BLANK()
)
