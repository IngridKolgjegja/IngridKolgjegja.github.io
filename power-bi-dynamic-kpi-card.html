How to Create a Dynamic KPI Card in Power BI

Dynamic KPI cards are useful when you want a Power BI card to react to filters, slicers or user selections instead of always showing the same value.

Example scenario

Imagine you have a sales dashboard and you want a card to show total sales for the current filter selection.

Start with a basic measure: 

Total Sales =
SUM(Sales[Amount])

If the user filters by country, product, date or customer, the card will update automatically.

Dynamic label using SELECTEDVALUE

You can also create a dynamic label that changes depending on the user's selection. 

Selected Product Label =
SELECTEDVALUE(
    Products[Product Name],
    "All Products"
)

If one product is selected, Power BI returns that product name. If multiple products or no single product are selected, it returns "All Products".

Dynamic KPI title

You can combine text with a dynamic selection: 

KPI Title =
"Sales - " &
SELECTEDVALUE(
    Products[Product Name],
    "All Products"
)

The result could be: 

Sales - Laptop

or: 

Sales - All Products

Show a value only when something is selected

Sometimes you may want the card to stay blank until the user selects a specific item. 

Selected Product Sales =
IF(
    HASONEVALUE(Products[Product Name]),
    [Total Sales],
    BLANK()
)
Tip: SELECTEDVALUE, HASONEVALUE and ISFILTERED are very useful when building interactive dashboards.

Why dynamic KPI cards are useful

  • They make dashboards easier to understand.
  • They react to user selections.
  • They reduce the need for multiple separate cards.
  • They help create more interactive reports.
