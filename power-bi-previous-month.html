How to Calculate Previous Month in Power BI

Comparing the current period with the previous month is one of the most common tasks in Power BI. In this tutorial, you'll learn a simple way to calculate the previous month's value using DAX.

Example scenario

Imagine you have a sales table and a calendar table. You already have a measure for total sales: 

Total Sales =
SUM(Sales[Amount])

Now you want to calculate the same value for the previous month.

Previous month measure

Previous Month Sales =
CALCULATE(
    [Total Sales],
    DATEADD(
        Calendar[Date],
        -1,
        MONTH
    )
)

How it works

The CALCULATE function changes the filter context of the measure.

DATEADD shifts the current date context back by one month. This means Power BI evaluates [Total Sales] for the previous month instead of the current one.

Important: your calendar table should contain a continuous date column and should be correctly related to your fact table.

Calculate the difference

You can also calculate the difference between the current month and the previous month: 

Month Difference =
[Total Sales] - [Previous Month Sales]

Calculate percentage change

Month Change % =
DIVIDE(
    [Total Sales] - [Previous Month Sales],
    [Previous Month Sales]
)

This is useful for KPI cards and performance dashboards.

Common problem

If the measure returns blank or unexpected values, check that:

  • your calendar table is connected correctly
  • the date column contains continuous dates
  • you are using the calendar table in your visual
