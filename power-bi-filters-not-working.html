Why Power BI Filters Are Not Working

If a slicer, chart or filter is not affecting another visual in Power BI, the problem is usually related to visual interactions, relationships between tables or the filter context used by your measure.

1. Check visual interactions

Power BI lets you control whether one visual filters, highlights or ignores another visual.

Select the visual you want to use as the filter, then go to: 

Format → Edit interactions

Power BI will display interaction icons above the other visuals. Make sure the filter icon is selected for the visual you want to filter.

Common issue: if the interaction is set to "None", clicking a bar or slicer will not affect that visual.

2. Check the relationships between your tables

If the field used in your filter comes from a different table, Power BI needs a valid relationship between the tables.

Open the Model view and check:

  • whether the tables are connected
  • whether the relationship is active
  • the relationship cardinality
  • the cross-filter direction

A missing or incorrect relationship is one of the most common reasons filters do not behave as expected.

3. Check which column your visual uses

Sometimes two columns look similar but come from different tables. For example: 

DIM_PRODUCT[Category]

and

FACT_SALES[Category]

may contain similar values, but they do not necessarily behave the same way in the model.

In most star-schema models, dimensions should be used for slicers and categories, while measures are calculated from the fact table.

4. Check whether your DAX measure removes filters

A measure can deliberately ignore filters. For example: 

Total Sales All Products =
CALCULATE(
    [Total Sales],
    ALL(Products)
)

The ALL function removes filters from the Products table. This means a product slicer may appear to have no effect on this measure.

5. Check page-level and report-level filters

Sometimes the problem is not the visual itself. Open the Filters pane and check:

  • Filters on this visual
  • Filters on this page
  • Filters on all pages

Another filter may already be restricting the data shown in the visual.

6. Test the filter with a simple table

If you are not sure where the problem is, create a temporary table visual.

Add:

  • the field you are filtering by
  • the measure you are testing

Then interact with your slicer or chart. This helps you determine whether the issue is in the data model, the measure or the visual interaction.

Quick checklist

  • Is the visual interaction enabled?
  • Are the tables related?
  • Is the relationship active?
  • Are you using the correct dimension column?
  • Does the DAX measure use ALL or REMOVEFILTERS?
  • Are other page or report filters active?
